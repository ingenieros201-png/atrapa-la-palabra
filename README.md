# Atrapa la palabra

Juego de mecanografía en un solo archivo HTML. Las palabras caen desde arriba y hay que escribirlas antes de que toquen el suelo.

## Cómo jugar

1. Abre `atrapa-la-palabra/index.html` en cualquier navegador moderno. No necesita instalación ni servidor.
2. Pulsa **Jugar**.
3. Escribe las palabras que caen. Al teclear, se resalta la palabra que coincide.
4. Cada palabra que toca el suelo te quita una vida. Tienes 3 vidas.

## Detalles

- Los acentos son opcionales: escribir `arbol` cuenta como `árbol`.
- La velocidad y la frecuencia de las palabras aumentan con los puntos.
- El récord se guarda en el navegador (`localStorage`).
